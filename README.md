### 🌟 Featured Project: Eagle-1-64Bit

<div align="center">

[![Eagle-1-64Bit Repo](https://img.shields.io/badge/Repo-Eagle--1--64Bit-brightgreen?style=for-the-badge&logo=github)](https://github.com/paulp143/Eagle-1-64Bit)

</div>

**Eagle-1-64Bit** is a 2D top-down arcade space combat and close-air-support (CAS) game built from scratch in Python (`pygame-ce`).

- **Aerial Dogfighting & Ground Support**: Pilot *Eagle-1* across a 3000×3000 scrolling battlefield while coordinating stratagem strikes and CAS beacons for an allied ground squad.
- **Dynamic AI Systems**: State-driven allied ground infantry, hostile Automaton troop waves, automated fabricators, and heavy boss encounters.
- **Procedural Audio Pipeline**: Dedicated standalone procedural audio waveform synthesizer and real-time audio channel routing.
- **Robust Tactical UI**: Multi-tab in-game manual, predictive weapon reticles, and real-time radar systems.

👉 Check out the source code and gameplay mechanics: [paulp143/Eagle-1-64Bit](https://github.com/paulp143/Eagle-1-64Bit)
